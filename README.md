# Secure Hybrid Datacenter Network Security

## Overview

A hands-on project exploring how to secure communication between an enterprise private datacenter and public cloud applications.

## Objectives

- Design isolated application networks.
- Implement least-privilege IAM and network access controls.
- Secure communication between private and public cloud environments.
- Explore Kubernetes network segmentation.
- Test and document attack containment.
- Automate infrastructure using Infrastructure as Code.

## Technology Stack

- Ubuntu / Linux
- TCP/IP networking
- Git and GitHub
- AWS VPC, IAM, security groups and routing
- Terraform
- Docker and Kubernetes
- Python and shell scripting

## Repository Structure

- `docs/` — Learning notes and technical documentation
- `architecture/` — Network diagrams and design decisions
- `scripts/` — Automation and testing scripts
- `infrastructure/` — Infrastructure as Code
- `tests/` — Security validation and test evidence

## Security Principles

Least privilege, network segmentation, defense in depth, explicit authorization, and continuous validation.
